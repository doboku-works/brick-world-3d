# 🧱 ブロックワールド 3D（Brick World 3D）

子供から大人まで安心して遊べる、完全無料・完全ローカル動作の3Dブロック建築＆探検ゲームです。

## ✨ 主な特長

- **広大な 128×128 スタッド × 高さ 96 プレート（32段以上！）のワールド**
  - 街・お城・遊園地・空港・宇宙基地を同じワールドにいくつも並べて作れます。
  - 4種類のワールド地形（みどりのはらっぱ／まちのどうろ／うみとしま／うちゅうきち）と4つの時間帯（あさ／ひる／ゆうがた／よる）をいつでも切り替え可能。
- **61種類の立体パーツ & 33色のカラーパレット**
  - 基本ブロック、プレート、つるつるタイル、屋根スロープ、アーチ、窓、ドア、階段、光るライト・街灯、車輪セット、フロントガラス、翼、プロペラ、木、花、宝箱、オリジナルブロックにんぎょう、ブロックいぬ、ロボット顔まで勢ぞろい。
  - 通常カラー・クリア（半透明）・メタリック・夜に光るネオンカラーが使えます。
- **かんせい「はんこ（スタンプ）」機能 & マイスタンプ**
  - おうち・お城・スポーツカー・パトカー・トラック・ロケット・巨大ロボ・機関車・飛行機・アーチ橋・灯台などをワンクリック配置！置いた後は1ブロック単位で自由に改造できます。
  - 自分で作った作品を「マイはんこ」に登録することも可能。
- **「あそぶ！」探検 & くるまドライブモード**
  - 作った世界の中を、オリジナルブロックにんぎょうで歩いたりジャンプしたり（1人称・3人称切替）、ブロックカートでドライブ＆クラクション演奏できます。
- **「ドカーン！」テストくずし & まきもどし**
  - ブロックを物理シミュレーションで豪快に吹き飛ばして遊んだあと、「まきもどす」ボタンひとつで元どおりに復元できます。
- **🔒 完全無料・完全オフライン＆安全設計**
  - 外部サーバー通信・広告・課金・トラッキング・アカウント登録は一切ありません。
  - セーブデータはお使いのブラウザ内（`localStorage`）およびローカルのJSONファイルにのみ保存されます。

## 🚀 遊び方（起動方法）

`play.bat` をダブルクリックするか、ターミナルで以下を実行してください。

```powershell
cd D:\Dev\projects\brick-world-3d
npm run dev
```

ブラウザで `http://localhost:5173` を開くとすぐに遊べます。
